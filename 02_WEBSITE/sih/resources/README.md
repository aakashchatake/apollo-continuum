# SIH 2026 - D Y Patil Intelligent Soil Team

## Purpose

This workspace is the guided SIH 2026 delivery for the D Y Patil team under the
Apollo AgriVerse initiative of Chatake Innoworks Private Limited. It is a new
student build, informed by Apollo Mission 1 and the active Intelligent Soil
expansion; it does not replace either project.

## Project Name

**Physics-Informed Digital Twin for Intelligent Soil Systems**

Water-efficient precision agriculture using stimuli-responsive hydrogels and
hybrid state models.

## Deliverables

- `01_SIH_6_SLIDE_SUBMISSION_CONTENT.md`: exact copy and visual direction for
  the required six-slide SIH submission.
- `02_TEAM_BRIEFING_AND_EXECUTION_ROADMAP.md`: the detailed explanation,
  technical architecture, material rationale, MVP and evaluation plan.
- `03_ROLES_AND_DAILY_PLAN.md`: owner-based work plan for the six-person team.
- `04_SIH_SCOPE_AND_INDUSTRY_MENTORING_MODEL.md`: the boundary between Apollo's
  internal workstreams and the external SIH work package.
- `04_PRESENTATION/`: six-slide SIH presentation source, presentation file and
  final submission PDF.
- `05_MVP_PROTOTYPE/`: standalone browser prototype for the Intelligent Soil
  Decision Workbench. It currently runs at `http://127.0.0.1:8092/`.
- `06_TEAM_WORKFLOW_AND_PRESENTATION_SCRIPT.md`: the work breakdown, daily
  workflow, six-member scripts, two-minute fallback speech and judge Q&A.

## Scope Boundary

The hackathon MVP demonstrates a decision-support digital twin using simulated
and manually entered inputs. It must clearly label all water-saving outputs as
modelled scenarios until field trials establish them. The team must not claim
that a new hydrogel formulation, a production IoT system, or a real farm
deployment has already been validated.

## Apollo Continuity

Apollo Mission 1, including the `Apollo-Krishi-Rakshak` repository, is useful
as lineage and a product reference. Apollo AgriVerse Intelligent Soil is a
separate 2026 expansion project. The D Y Patil team should build a clean SIH
prototype rather than fork or extend the old repository without review.
