# Apollo AgriVerse - AgriIntel Team Workspace

## Purpose

This is the internal Mission II work package for the four-member Apollo AgriVerse - AgriIntel internship team. It is a student engineering contribution to the wider Apollo AgriVerse programme, not ownership of Apollo itself.

## Project Focus

**AgriIntel: explainable crop and field intelligence for precision-farming decisions.**

The team is building one coherent, reviewable vertical slice: structured field inputs become an evidence-labelled crop or field insight, with a clear reason, confidence state and next action. The goal is not a generic chatbot, a full farm ERP, or an unsupported claim of agricultural accuracy.

## Non-Negotiable Rules

- Keep the registered repository as the working source: `Vijayalaxmi-ks/Apollo_AgriVerse`.
- Do not publish real farmer records, private images, credentials, API keys or unlicensed datasets.
- Label synthetic, demo and modelled results honestly.
- Do not claim model accuracy, disease diagnosis, water saving or field deployment without a traceable evaluation record.
- Keep Apollo Mission I attribution, SIH Intelligent Soil and Mission II work distinct.

## What Counts as a Strong MVP

1. A user can enter or load a bounded field scenario.
2. The system validates the input and records what is missing or uncertain.
3. A baseline analysis produces a visible result, reason and confidence level.
4. The dashboard makes the next step understandable to a non-technical reviewer.
5. The repository runs from documented instructions and includes a small deterministic test set.
